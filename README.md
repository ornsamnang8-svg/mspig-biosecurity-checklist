# MsPIG Biosecurity Checklist

**ត្រួតពិនិត្យជីវៈសុវត្ថិភាពកសិដ្ឋាន | M's PIG**

កម្មវិធីត្រួតពិនិត្យជីវៈសុវត្ថិភាព (Biosecurity Audit) សម្រាប់កសិដ្ឋានជ្រូក — ជា single-file HTML ដំណើរការបានដោយគ្មានអ៊ីនធឺណិត (offline)។

A single-file, offline-capable HTML web app for auditing pig-farm biosecurity, in Khmer.

## 🔗 ប្រើប្រាស់ / Live app

👉 https://ornsamnang8-svg.github.io/mspig-biosecurity-checklist/

## លក្ខណៈពិសេស / Features

- ឯកសារតែមួយ (`index.html`) — គ្មាន build, គ្មាន server
- ដំណើរការលើទូរស័ព្ទ, ថេប្លេត និងកុំព្យូទ័រ
- រក្សាទុកទិន្នន័យក្នុងឧបករណ៍ (localStorage)
- នាំចេញជា PDF / Excel / CSV
- អក្សរខ្មែរ (Kantumruy Pro, Battambang)

## របៀបប្រើ / Usage

បើកតាម link ខាងលើ ឬទាញយក `index.html` រួចបើកដោយ browser ណាមួយ។

Download `index.html` and open it in any browser — no installation required.
